# TemuIn — Kampus Lost & Found Hub

TemuIn adalah platform web terpusat berbasis pemetaan gedung kampus yang
memfasilitasi pencarian dan pengembalian barang hilang secara cepat,
transparan, dan aman bagi mahasiswa bermobilitas tinggi.

Dibuat untuk **ISE! Academy 2026 — Digital Product Development**
oleh Kelompok Pluto (Hendy Azzamuddin Firdaus & Moch Fadillah Pratama).

## Fitur MVP
1. **E-Katalog Barang Temuan** — pencarian & filter berdasarkan lokasi gedung dan kategori.
2. **Formulir Lapor Cepat** — form input barang temuan/hilang di bawah 1 menit.
3. **Modul Kuis Verifikasi Kepemilikan** — mencegah klaim palsu tanpa membuka data pribadi.

## Progress

- **Progress 1** — Problem discovery, user research, wireframe & high-fidelity mockup (Figma).
- **Progress 2** — Implementasi front-end halaman utama: struktur HTML5 semantic,
  styling CSS (warna, tipografi, box model), layout Flexbox (navbar & footer),
  layout Grid (kartu barang), dan Responsive Design (2 breakpoint).

## Cara Menjalankan (Frontend)

1. Buka folder `frontend/` di VS Code.
2. Install ekstensi **Live Server**.
3. Klik kanan `index.html` → **Open with Live Server**.
